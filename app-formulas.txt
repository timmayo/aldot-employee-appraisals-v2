APPRAISAL POC - POWER FX (canvas app)

This file matches the app as built in Power Apps Studio (pasted from Studio YAML,
modern controls turned on). Names are display names from data-model.md. Where a
formula depends on how your environment exposes a table or choice, confirm the
exact name with IntelliSense in the formula bar.

Screens (9): scrHome, scrNewAppraisal, scrPreFront, scrPreBack, scrMid,
scrAnnualFront, scrDisciplinary, scrAnnualBack, scrDates.

Data sources: Appraisals, Responsibilities, Disciplinary Actions, Corrective
Action Plans, Appraisal Signatures, Appraisal Settings, Rating Scale, Users, Teams.

Global variables: gUser, gSettings, gIsASA, gAppraisal, gNew, gIsRater,
gIsReviewer, gIsEmployee, gDaysLeft, gCanEditResp, gRatableCount, gRatedCount,
gRespScore, gDiscCount, gDiscScore, gDiscComplete, gGateOpen, gPerfScore.
Collections: colResp, colScale.


=============================================================
RULES LEARNED WHILE BUILDING (apply to every screen)
=============================================================
1. Select() only works on a control on the SAME screen. There is no shared
   recalculation button. Each screen that needs it has its own hidden button
   (see RECALC below):
     scrPreFront     btnRecalc
     scrMid          btnRecalcMid
     scrAnnualFront  btnRecalcAnnFront
     scrDisciplinary btnRecalcDisc
     scrAnnualBack   btnRecalcAnnBack
   Each screen's OnVisible and every formula that changes data calls its own button.
2. Control names must be unique across the app. Studio adds a suffix (_1, _3...)
   to a pasted duplicate. That is harmless for decoration, but any control that a
   formula refers to has a unique name (galMidResp, txtMidNewResp, and so on).
3. Dataverse choice columns:
     - A saved choice (gAppraisal.Attendance) is an option value. It has no
       .Value and cannot be compared with text.
     - Choices(Table.Column) returns records whose Value column is also an option
       value. Compare option to option:
           LookUp(Choices(Appraisals.Attendance), Value = gAppraisal.Attendance)
     - Show labels with Text(ThisItem.Value).
     - Dropdown .Selected is a record. Save it with .Selected.Value.
     - Enum names follow the pattern 'Stage (Appraisals)', 'Cycle Type (Appraisals)',
       'Mid Feedback Rating (Appraisals)'.
4. AddColumns takes the new column names as bare identifiers, not strings:
   AddColumns(tbl, IsRatable, ...) and not AddColumns(tbl, "IsRatable", ...).
5. Modern controls (current versions): ModernDropdown@1.0.3, ModernDatePicker@1.0.2,
   ModernTextInput@1.1.2, ModernCheckbox@1.0.2, ModernCombobox@1.0.0.
     - Dropdown: Items, ItemDisplayText, Default, OnChange, .Selected
     - Combobox: Items, ItemDisplayText, SelectMultiple=false, IsSearchable, .Selected, .SearchText
     - Date picker: DefaultDate, .SelectedDate
     - Text input: Default, Type (TextInputType.Multiline), Placeholder, .Text
     - Checkbox: Label, Default, OnCheck, OnUncheck, read with .Checked
       (Value, OnChange and Checked-as-an-input are not valid on this control)
6. A Label has no corner radius. Rounded pills (stage badge, step pills, user
   chip) are Classic/Button controls with HoverFill and PressedFill set to the
   same colour as Fill, and no OnSelect.
7. YAML pasted into Studio: no ": " (colon plus space) inside a single-line value.
   Use a |- block for any formula that contains a record such as {Name: value}.
8. Press Play (or Alt+click) to test; a plain click in the editor only selects.
   Run App.OnStart (App, ..., Run OnStart) after changing it.

=============================================================
RECALC - the hidden button's OnSelect (paste into each button listed in rule 1)
 Visible = false, X 0, Y 0, Width 10, Height 10.
=============================================================
ClearCollect(
    colResp,
    AddColumns(
        AddColumns(
            Filter(Responsibilities, Appraisal.Appraisal = gAppraisal.Appraisal),
            IsRatable,
            DateDiff('Date Added', Coalesce('Date Ended', Today()), TimeUnit.Days) >= gSettings.'Min Observation Days'
        ),
        Points,
        LookUp(colScale, 'Rating Value' = Rating, 'Responsibility Points')
    )
);
Set(gRatableCount, CountRows(Filter(colResp, IsRatable)));
Set(gRatedCount, CountRows(Filter(colResp, IsRatable, !IsBlank(Rating))));
// responsibility score = average of the mapped points (0-10)
Set(
    gRespScore,
    If(gRatedCount = 0, 0, Round(Sum(Filter(colResp, IsRatable, !IsBlank(Rating)), Points) / gRatedCount, 1))
);
Set(gDiscCount, CountRows(Filter('Disciplinary Actions', Appraisal.Appraisal = gAppraisal.Appraisal)));
// no actions listed = 0; otherwise the rater's disciplinary rating maps to points (0-10)
Set(
    gDiscScore,
    If(gDiscCount = 0, 0, Coalesce(LookUp(colScale, 'Rating Value' = gAppraisal.'Disciplinary Rating', 'Disciplinary Points'), 0))
);
Set(gDiscComplete, gDiscCount = 0 || !IsBlank(gAppraisal.'Disciplinary Rating'));
Set(gGateOpen, gRatableCount > 0 && gRatedCount = gRatableCount && gAppraisal.'Disciplinary Reviewed' && gDiscComplete);
Set(gPerfScore, If(gGateOpen, Max(0, gRespScore - gDiscScore), Blank()));
// 90-day rule: who may change responsibilities right now
Set(gDaysLeft, DateDiff(Today(), gAppraisal.'Appraisal Year End', TimeUnit.Days));
Set(
    gCanEditResp,
    If(
        gAppraisal.Stage = 'Stage (Appraisals)'.'Pre - ASA Setup', gIsASA,
        gAppraisal.Stage = 'Stage (Appraisals)'.'Pre - Supervisor Review', gIsRater,
        gAppraisal.Stage = 'Stage (Appraisals)'.'Mid - Open', gIsRater && gDaysLeft >= gSettings.'Min Observation Days',
        false
    )
)

scrNewAppraisal (ASA creates the appraisal row)
=============================================================
// Screen OnVisible
Reset(cmbEmployee);
Reset(ddCycleType);
Reset(cmbRater);
Reset(cmbReviewer);
Reset(dpYearStart);
Reset(dpYearEnd);
Reset(txtPosition);
Reset(txtDivision)

// cmbEmployee.Items (cmbRater and cmbReviewer are the same with their own SearchText)
Filter(Users, StartsWith('Full Name', cmbEmployee.SearchText))
// cmbEmployee.ItemDisplayText
ThisItem.'Full Name'
// SelectMultiple = false, IsSearchable = true

// ddCycleType.Items
Choices(Appraisals.'Cycle Type')
// ddCycleType.ItemDisplayText
Text(ThisItem.Value)
// ddCycleType.Default
LookUp(Choices(Appraisals.'Cycle Type'), Value = 'Cycle Type (Appraisals)'.Standard)

// dpYearEnd.DefaultDate (one year after the start, minus one day)
If(IsBlank(dpYearStart.SelectedDate), Blank(), DateAdd(DateAdd(dpYearStart.SelectedDate, 1, TimeUnit.Years), -1, TimeUnit.Days))

// btnCreate.DisplayMode
If(
    !IsBlank(cmbEmployee.Selected)
        && !IsBlank(cmbRater.Selected)
        && !IsBlank(cmbReviewer.Selected)
        && !IsBlank(dpYearStart.SelectedDate)
        && !IsBlank(dpYearEnd.SelectedDate)
        && dpYearEnd.SelectedDate > dpYearStart.SelectedDate
        && !IsBlank(txtPosition.Text),
    DisplayMode.Edit,
    DisplayMode.Disabled
)

// btnCreate.OnSelect
Set(
    gNew,
    Patch(
        Appraisals,
        Defaults(Appraisals),
        {
            Name: cmbEmployee.Selected.'Full Name' & " " & Year(dpYearStart.SelectedDate),
            Employee: cmbEmployee.Selected,
            'Rating Supervisor': cmbRater.Selected,
            'Reviewing Supervisor': cmbReviewer.Selected,
            'Cycle Type': ddCycleType.Selected.Value,
            'Appraisal Year Start': dpYearStart.SelectedDate,
            'Appraisal Year End': dpYearEnd.SelectedDate,
            'Position Title': txtPosition.Text,
            Division: txtDivision.Text,
            Stage: 'Stage (Appraisals)'.'Pre - ASA Setup'
        }
    )
);
If(
    IsEmpty(Errors(Appraisals)),
    Notify("Appraisal created", NotificationType.Success);
    Refresh(Appraisals);
    Navigate(scrHome),
    Notify(First(Errors(Appraisals)).Message, NotificationType.Error)
)
